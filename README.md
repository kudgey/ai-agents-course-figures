# Схеми курсу «Прикладні ШІ-агенти та системи на основі великих мовних моделей»

Оригінальні навчальні схеми до лекційного курсу (КПІ, спеціальність 122, магістратура).

Репозиторій існує з однією технічною метою: дати схемам постійні публічні URL, щоб
Gamma могла забрати їх під час генерації презентацій і покласти на власний CDN.

## Що тут є

Тільки **власні схеми курсу** — намальовані з нуля під тему презентацій, підписи
українською. Схем зі сторонніх джерел (книжок, статей, документації) тут **немає**:
у презентаціях вони стоять прямими посиланнями на першоджерело зі зноскою.
